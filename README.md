# 🚀 Solar3D Space Survivor

A modern 2D arcade space survival game built using Solar2D (formerly Corona SDK).

Features

- Animated space background
- Player spaceship
- Asteroid spawning
- Collision detection
- Score system
- Sound effects
- Game Over screen
- Responsive UI
- Optimized for desktop and mobile

Technologies

- Solar2D
- Lua
- Git
- GitHub

Project Structure

```
assets/
scenes/
scripts/
ui/
docs/
main.lua
config.lua
build.settings
```
